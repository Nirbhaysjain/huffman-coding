# Huffman Coding (Python)

This project implements the Huffman Coding algorithm for lossless text compression.

## Concepts Used
- Greedy Algorithm
- Min Heap (Priority Queue)
- Binary Tree

## Features
- Builds frequency map of characters
- Constructs Huffman Tree using heap
- Generates prefix-free binary codes
- Encodes and decodes text
- Displays compression ratio

## Example

Input:
hello world

Output:
- Encoded binary string
- Decoded original text
- Compression statistics

## How to Run

```bash
python huffman.py
```
